# Anchorline Systems

Several monitoring systems can report activity during the same shift. The security operations center needs to decide which alerts an analyst should see first. Its triage agent runs inside the existing on-premises monitoring environment. A missed alert can leave an intrusion undetected. An unnecessary escalation can disrupt an employee’s work.

You will advise the security operations team, evaluate a classifier on synthetic alert records, and review Threadline Security’s proposal for SentinelIQ. The team must be able to reconstruct why a particular alert was prioritized.

Your chosen client applies to all three independent tasks.
